# VTA-502 source-crop replay: visual-footprint candidate experiment

> **Local/future-checkpoint note:** The evaluator, script, manifests, configs, and tests cited here are not included in a docs-only published checkout until a dependency-complete code checkpoint is included. The command is a local/future recipe, not runnable from docs alone; see [`PUBLISH_BOUNDARY.md`](PUBLISH_BOUNDARY.md).

`uv run python scripts/evaluate_smoke_source_vta502.py --video /path/to/local-vod.mp4` replays four fixed 360×400 raw source crops against the exploratory HSV/shape profile. The train frames are 149400 and 149220; locked holdout frames are 150300 and 150360. The evaluator checks the VOD filename, dimensions, actual FPS, seek positions, and decoded crop SHA-256 hashes for those four scoring frames plus the independent visual-review evidence frames before emitting results. It does not hash-check every legacy `samples` entry: in particular, historical frames 150308, 150315, and 150322 are not part of this replay unless independently added to the review evidence or selected as scoring frames. Optional `--output` writes JSON only after evaluation succeeds. This is a reproducibility check of source pixels and candidate detections, not production validation.

## Evidence correction

An independent raw-frame reconciliation was added to `docs/smoke_source_observation_vta502.json`. It finds visual appearance only, with moderate smoke plausibility and caster attribution `UNKNOWN`. The teal-rimmed dark circle is absent at 2487.75s, visible at 2488.00s near (267,160), and shifts toward (253,154) through 2489.50s. A faint gray circular footprint is visible at 2489.75s, 2490s, and 2505s near (251,155); its rendering changes with ADS at 2489.75s. Whether the teal circle and gray footprint are the same feature is unresolved. Per-frame evidence hashes are recorded in the manifest.

Accordingly, the replay reports only candidate counts and detections near the approximate visual-footprint center (±3 source-crop pixels). It emits no smoke true-positive, false-positive, false-negative, precision, recall, or onset/duration metrics. Its output explicitly marks smoke precision/recall and timing as `NOT_ESTABLISHED_IDENTITY_UNRESOLVED`; production acceptance is false. The approximate footprint center is exploratory, not a canonical map coordinate or a smoke label.

The original manifest's sample kinds and timing bounds have been retained unchanged as historical reviewer assertions for provenance. They must not be treated as reconciled smoke labels: the sparse frames do not establish continuous duration, an exact smoke onset, or smoke presence/absence ground truth. The former appearance/persistence/end brackets are not emitted as accepted timing results. Historical boundary hashes are not required by this replay and are not reported as verified unless their frame also appears in the scoring set or independent visual-review evidence.
