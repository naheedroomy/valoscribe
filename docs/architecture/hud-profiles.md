# HUD profiles and minimap crops

Existing Valoscribe profiles store tournament-specific HUD rectangles in
`regions`; the legacy `regions.minimap` crop remains unchanged for compatibility.
Those coordinates are not considered calibrated by the new minimap API.

A profile that opts into the validated minimap crop adds explicit frame
dimensions and a top-level rectangle:

```json
{
  "frame_width": 320,
  "frame_height": 180,
  "minimap": {"x": 40, "y": 34, "width": 18, "height": 18}
}
```

These values are synthetic test geometry only, not production crop coordinates.
`Cropper.crop_minimap(frame)` checks that the image is a non-empty 3- or
4-channel array, that its width and height match the profile, and that the
integer rectangle is positive and fully inside the frame. Invalid configured
profiles raise `ValueError` rather than silently clipping or returning a
misleading crop. A profile with no top-level `minimap` returns an empty image;
`crop_all_regions` retains the `minimap` key for callers. Existing profiles with
only `regions.minimap` continue to use the legacy crop path and retain their
previous behavior and output keys.

Crop geometry tests use the deterministic synthetic anchors generated by
`tests/fixtures/generate_synthetic_frame.py`; they make no claim about the
user-provided VOD or tournament HUD coordinates. Real profile coordinates must
be measured from permitted source frames and recorded with their provenance.
