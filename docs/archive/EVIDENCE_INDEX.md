> **Publication boundary:** Referenced artifacts can be local, or included in a checkout only through an explicitly enumerated, reviewed, dependency-complete code checkpoint. This index does not imply code is universally absent from checkouts. See [`../architecture/publish-boundary.md`](../architecture/publish-boundary.md) and verify each checkpoint's referenced paths and version in the checkout under review. The six-file VTA-101 limited checkpoint is version-specific; the earlier docs-only commit `56e45e7` does not contain it. Do not assert a push or other publication without verification against an actual commit SHA; see [`vta101-code-checkpoint.md`](vta101-code-checkpoint.md).

This index distinguishes local worktree artifacts from external source media and synthetic tests. A present metadata/manifest document does not imply its associated code, source frames, or crops are included in a given checkout. SHA-256 binding detects source mismatch; it does not prove a label is correct. Real-source acceptance remains open as shown in [`project-status-legacy.md`](project-status-legacy.md).
