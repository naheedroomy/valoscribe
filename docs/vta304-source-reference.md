# VTA-304 source-reference evidence mechanics

This additive contract supports a frozen, independently reviewed source-reference set and a separate detector-candidate join. Its labels are **AI-reviewed source reference labels, not human gold**. A content hash binds the serialized manifest and annotations; freeze refuses replacement and readback checks canonical bytes, digest, expected source hash, Pydantic contracts, frame inventory, and per-annotation PTS boundaries.

`SourceReferenceManifest` requires a complete sequential frame/PTS inventory inside exact round bounds, rational timebase, explicit live/non-live/unknown frame classification, evidence-backed independent inventory review/adjudication, complete annotation review for each live frame, and a disjoint 3-development / 2-validation / at-least-1-test round allocation. Annotation intervals must terminate at the next certified source PTS, remain within live play, and carry independent blind reviewer/adjudicator identities, claim confidence/evidence, resolved disagreement provenance, and explicit non-human-gold status. Nominal FPS and sparse interval extrapolation are not used.

`join_reference_candidates` runs only after source labels exist and joins on exact frame index plus a configured geometric overlap threshold. It binds candidate-run, raw-candidate, and join-protocol digests; ambiguous and missed source markers remain unmatched in the evaluation accounting. It does not accept or inspect tracker identity predictions. Evaluation preserves all reviewed visible-player duration (D), established-identity duration (K), and verified-correct duration (C), while reporting unknown identity, class-uncertain, unmatched, and assignment coverage separately. Switches count only across exactly contiguous reviewed intervals with explicitly continuous source context; death, replay, and unsupported-gap boundaries are excluded. Missing joins/predictions make the metric unavailable rather than a successful zero-error result.

This slice implements synthetic mechanics only. It does not annotate or decode real rounds, certify human accuracy, produce `player_tracks.parquet` identity acceptance, tune thresholds, or satisfy full VTA-304. Real source-supported full-round labels, certified identity predictions, measured selected-fixture metrics, and stable-identity debug playback remain pending.
